## Entity Matching Notes

File 1 and File 2 overlap for all 12 ISM projects. Name differences are due to:
- Subsidiary vs. parent company names (e.g. TEPL/TSAT in File 1 vs. TEPL only in File 2)
- JV naming conventions (HCL-Foxconn vs. Vama Sundari Investments / Foxconn India)
- Trade name vs. legal name (CG Semi vs. CG Power and Industrial Solutions Ltd.)

All matching is based on a **manually reviewed, transparent lookup table** in `tests/audit_data.py` (`ENTITY_MAP`). No fuzzy/probabilistic matching is used.

---

## Official Source Date Clarification

The `official_source_date` column in File 2 is the **PIB data-collection date** (when the press release was retrieved), not the project approval date. For most projects it is `01-Apr-2026`. It is **never used** as an approval date in any preprocessing step. Approval dates come exclusively from the `approval_period` column in File 1.
