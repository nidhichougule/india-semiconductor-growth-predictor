# India Semiconductor Growth Predictor

> **A data science project that analyses India's government-approved semiconductor investments,
> builds forecasting models for cumulative investment growth (FY2023–FY2030), and presents
> findings through an interactive Streamlit dashboard.**

---

## 🇮🇳 Project Overview

India's semiconductor sector is undergoing a historic transformation driven by the
**India Semiconductor Mission (ISM)** and the ₹76,000-crore **Semicon India Programme**.
This project systematically tracks every government-approved semiconductor project,
engineers time-series features, and forecasts cumulative investment and market growth
through 2030.

### Prediction Target

| Target | Description |
|--------|-------------|
| **Primary** | Cumulative approved investment (₹ crore) by quarter, FY2023–FY2030 |
| **Secondary** | Number of new project approvals per quarter |
| **Tertiary** | Market demand (USD billion) using IESA/NITI Aayog CAGR parametric model |

## 📊 Data Sources

All data used in this project is sourced from verified government publications.
No fabricated or unverified data is committed to this repository.

| Source | Description | Credibility |
|--------|-------------|-------------|
| [PIB — Press Information Bureau](https://pib.gov.in) | Official project approval announcements | ✅ Primary Govt |
| [India Semiconductor Mission (ISM)](https://ism.gov.in) | Programme details, approved projects | ✅ Primary Govt |
| [MeitY Annual Reports](https://meity.gov.in) | Ministry investment & policy data | ✅ Primary Govt |
| [NITI Aayog Semiconductor Roadmap](https://niti.gov.in) | 19% CAGR demand forecast to FY2030 | ✅ Govt Policy |
| [IESA / IBEF](https://ibef.org) | USD 103.4B market forecast by 2030 | ✅ Industry Body |

See [`data/raw/data_source_manifest.md`](data/raw/data_source_manifest.md) for full citation details.

## 🚀 Setup Instructions

### Prerequisites
- Python 3.10 or higher
- pip

### Installation

```powershell
# 1. Clone the repository
git clone https://github.com/nidhichougule/india-semiconductor-growth-predictor.git
cd india-semiconductor-growth-predictor

# 2. Create a virtual environment
python -m venv venv
venv\Scripts\Activate.ps1

# 3. Install dependencies
pip install -r requirements.txt
```

### Running the Dashboard (Phase 5+)

```powershell
streamlit run src/dashboard/app.py
```
